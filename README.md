## 👨‍💻 About Me

I'm a Computer Science student focused on **Java backend development**, with a growing interest in **systems engineering and low-level computer science**.

I enjoy understanding how applications work beyond the interface—from API design and database operations to networking, concurrency, and operating systems.

- ☕ Primary language: Java
- ⚙️ Backend focus: Spring Boot and REST APIs
- 🗄️ Data layer: PostgreSQL, MySQL, and caching fundamentals
- 🖥️ Systems interests: Linux, networking, operating systems, and concurrency
- 🚀 Goal: Build reliable software while understanding the systems underneath it

> **Backend first. Systems next. Fundamentals always.**
